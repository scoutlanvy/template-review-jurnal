# Petunjuk template

- Proyek ini template kosong review dan perbandingan dua artikel ilmiah lintas bidang.
- Pertahankan struktur bagian, empat tabel, warna kepala tabel, dan footer nomor halaman.
- Seluruh isian publik ditandai titik-titik; jangan memasukkan identitas pribadi atau jawaban terisi.
- Ketentuan format, panjang empat halaman, dan rubrik merupakan contoh yang dapat disesuaikan. Total bobot rubrik harus 100% jika diubah.
- Jangan mengarang referensi, DOI, metode, data, atau hasil penelitian.
- Setelah mengubah LaTeX atau skrip build, jalankan ./Compile-Tugas.ps1 dan periksa PDF serta luapan teks.
- PDF ReviewJurnal_NIM_Nama.pdf dibuat di root. Berkas sementara di tmp/build/tugas-review-jurnal/. Hasil build diabaikan Git.
- Nama skrip Compile-Tugas.ps1 dan folder build dipertahankan demi kompatibilitas perintah penggunaan.
